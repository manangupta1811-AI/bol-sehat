# BOL SEHAT

Hindi-first, voice-first health helper that prepares a Doctor Card. It does not diagnose.

- Single-file web app: `index.html` (HTML/CSS/JS, no server, no accounts, nothing is saved or sent).
- 8 adult topics, 119 doctor-style questions, general-care information from NHS pages.
- Voice input uses the browser's speech recognition (Chrome works best, Hindi hi-IN).
- Student prototype, not checked by doctors. For emergencies call 112 / 108.

Made by Manan Gupta for DSH Hacks V2. AI tools helped with code, wording and testing.
